Speaker note
Introduce LuxNote AI as a polished AWS final project built around a realistic luxury design workflow.

Problem

Luxury design work creates scattered project information.

  • Walkthrough notes, client preferences, builder updates, and vendor details are easy to lose.
  • Project managers need faster ways to identify priorities, next steps, and follow-up communication.
  • AI can help organize raw notes, while still requiring professional human review.
Project goal: build a cloud-based assistant that turns raw project notes into structured, review-ready project records.

Solution

LuxNote AI captures notes and returns organized project intelligence.

Input

Client name, project name, note type, source, and project notes.

AI Processing

Category, priority, key phrases, sentiment, summary, next steps, and draft message.

Output

Saved project record, project library, and printable report.

  • Designed for design studios, A/V integrators, lighting teams, and builder coordination.
  • Uses fictional records for the classroom demo.

Architecture

Serverless AWS workflow

User

Designer or PM enters project notes.

Amplify

Hosts the frontend.

API Gateway

Receives HTTP requests.

Lambda

Validates, routes, and processes.

Comprehend

Extracts key phrases and sentiment.

Bedrock

Generates summary and next steps.

DynamoDB

Stores the final record.

CloudWatch/IAM

Supports logs and permissions.

AWS Services

Each service has a clear role.

  • AWS Amplify hosts and deploys the frontend.
  • Amazon API Gateway exposes the backend HTTP API.
  • AWS Lambda handles validation, AI calls, routing, and persistence.
  • Amazon DynamoDB stores saved project records.
  • Amazon Comprehend provides key phrase and sentiment analysis.
  • Amazon Bedrock generates summaries, next steps, and draft messages.
  • CloudWatch and IAM support logging, monitoring, and permissions.

AI Workflow

Combining AI/ML with generative AI

Amazon Comprehend

Extracts key phrases and sentiment from submitted project notes.

Amazon Bedrock

Generates a concise summary, specific next steps, and a draft follow-up message.

Human Review

AI output is reviewed before use in client, builder, vendor, electrical, construction, or design decisions.

The Bedrock prompt is grounded in the original notes and should not invent dates, approvals, specifications, or commitments.

Data

The app saves structured records in DynamoDB.

  • recordId and createdAt timestamp
  • clientName and projectName
  • noteType, source, and original notes
  • category and priority
  • keyPhrases and sentiment
  • summary, nextSteps, and draftMessage
Why this matters

The design team gets searchable project memory instead of scattered notes. Each record can support follow-up, review, and project coordination.

Limits and Next Steps

Credible roadmap after the MVP

Current Limitations

The live classroom demo uses fictional data and a public API endpoint. Raw audio ingestion, floor-plan analysis, automatic message sending, and downloadable PDFs are not implemented yet.

Future Improvements

Enable Cognito private workspaces, add Plaud transcript ingestion, support project media libraries, generate PDFs, add role-based access, and create a client-ready approval workflow.

Closing statement: LuxNote AI proves how AWS serverless services and AI can support a real design-project workflow.
