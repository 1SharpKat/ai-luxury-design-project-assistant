# LuxNote AI Fictional Sample Data

This folder contains fictional data created only for testing, demonstrations, screenshots, and course evaluation.

No record represents a real client, company, address, or construction project.

## Files

- `demo-records.json` contains fictional records for the frontend and API demonstration.
- `lambda-test-event.json` contains a fictional AWS Lambda test event.
- `sample-request.json` contains an existing sample API request, when applicable.

## Recommended Demonstration Record

Use the Alder Ridge Residence record for the primary demonstration. It includes architectural lighting, A/V integration, builder coordination, an electrical walkthrough, and a deadline.

## Prohibited Information

Do not include:

- Real client names
- Real project addresses
- AWS account numbers
- Credentials or API keys
- Environment-variable values
- Private configuration values
- Presigned Amazon S3 URLs
- Confidential company information
